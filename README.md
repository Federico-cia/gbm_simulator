# Bitcoin GBM Simulator

Geometric Brownian Motion simulation of Bitcoin prices in Python. Minimal plain-Python simulator with optional plot. Original MATLAB code and thesis slides included. Research/education only.

Original MATLAB implementation: MATLAB/simulate_GBM.m  
Slides: docs/presentation/Presentazione_Tesi_finale.pptx

**Time step:** calendar-day discretization (dt = 1/365). **Units:** MU and SIGMA are annualized decimals.

```bash
python scripts\gbm_thesis_minimal.py
